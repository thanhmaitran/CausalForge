# Threats to validity
* Synthetic SCMs are low-dimensional and well-specified; rankings may not transfer.
* Honest-forest uncertainty is a heuristic; measured pointwise coverage is ~0.67–0.69 (nominal 0.95).
* PSM has no SE; IPW SE ignores propensity estimation (conservative); DML-PLR targets a weighted effect.
* Real-data benchmarks are implemented but were NOT run during development (no network).
* Criteo: ITT on assignment only; no individual ground truth, so no PEHE.
